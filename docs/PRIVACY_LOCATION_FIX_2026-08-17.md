| 구성요소 | 실제 위치 | 확인 명령 |

| **Cloud Storage** (아바타 이미지 등) | **`US-CENTRAL1` = 미국** | Storage JSON API `b/inconomysu-class.firebasestorage.app` |

> export/import 마이그레이션을 하고 코드의 DB 참조를 전부 바꿔야 한다 → 방학이 유일한 창.

> · 이전되는 항목: 닉네임(가명), 학급 코드, 서비스 이용 기록(로그인 시각, 가상 경제 활동 내역), 프로필 이미지

> · 이전 일시·방법: 서비스 이용 시점에 네트워크를 통해 상시 전송

> · 이전받는 자의 이용 목적: 클라우드 인프라 제공(저장·조회·인증)
> · 보유·이용 기간: 회원 탈퇴 또는 학년 종료 시까지

⚠️ 만 14세 미만 아동의 개인정보를 국외로 이전하므로, 이 동의는 **법정대리인 동의**여야 하고
**다른 동의와 묶지 말고 분리**해서 받아야 한다. 이미 동의서를 받은 학급은 **재동의**가 필요할 수 있다.

### 갈래 B — **서울로 옮기고** 지금 문구를 참으로 만든다 (겨울방학)

Firestore 새 DB(asia-northeast3) 생성 → export/import → 코드 DB 참조 교체 → Storage 버킷도 서울로.
이렇게 하면 **비용 1.5배 · 국외이전 법적 쟁점 · 함수(서울)↔DB(미국) 태평양 왕복이 한 번에 해결**된다(계획서 §2.2·P2-0).
다만 **그때까지의 기간은 여전히 갈래 A 가 필요하다** — "곧 옮길 예정"은 지금 잘못된 고지의 면죄부가 아니다.
